# 🚀 INICIO RÁPIDO - FENALCO Sur de Santander

## ⚡ En 3 Pasos

### 1️⃣ Instalar dependencias
```bash
cd fenalco-santander
npm install
```

### 2️⃣ Iniciar servidor de desarrollo
```bash
npm run dev
```

### 3️⃣ Abrir en el navegador
Visita: http://localhost:3000

## 🎨 Reemplazar Imágenes

1. Sube tus imágenes a `/public/images/`
2. Busca los placeholders que dicen `[IMAGEN: ...]`
3. Reemplázalos con:
```jsx
<img src="/images/tu-imagen.jpg" alt="Descripción" className="..." />
```
